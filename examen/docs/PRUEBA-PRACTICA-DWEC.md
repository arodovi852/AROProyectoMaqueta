# Jerarquía de componentes creada

Se han creado 2 componentes nuevos distintos:

- Componente padre: Se encarga de recibir los datos del backend para su componente hijo

- Componente hijo: El componente hijo es un componente standalone, donde se ha añadido un componente simple que funciona para representar la información de un componente Card (nombre, descripción...)
