1. Modal Component

Modals with ESC close, click outside content and close button. Implements @HostListener, @ViewChild and Renderer2.

Implemented features:

  • Close with ESC: Press Escape to close
  • Click outside: Click on dark background closes the modal
  • Close button: X in the upper right corner
  • Scroll blocked: Body doesn't scroll when modal is open
  • Focus trap: Focus stays inside the modal
  • Animations: Smooth enter/exit transitions

Client Phase 1 - Task 3

This is a functional modal with the following features:

  • Close with ESC key (@HostListener('document:keydown.escape'))
  • Close on click outside the content
  • Close button in the header
  • Blocks body scroll when open
  • Entry and exit animations
  • Accessibility with role="dialog" and aria-modal="true"

Technical implementation:

  • @ViewChild('modalContainer') for container reference
  • Renderer2.setStyle() to block body scroll
  • event.preventDefault() and event.stopPropagation()

4. Hamburger Menu (Header)

The hamburger menu is implemented in the page header. Look at the upper left corner (on mobile) or right.

Implemented features:

  • Toggle on click: Hamburger button opens/closes the menu
  • Close with ESC: @HostListener('document:keydown.escape')
  • Close on click outside: @HostListener('document:click', ['$event'])
  • Auto close on desktop: @HostListener('window:resize')
  • ARIA attributes: Dynamic aria-expanded, aria-label
  • CSS animations: Smooth menu transitions

Technical implementation:

  • @ViewChild('toggleBtn', {{ '{' }} read: ElementRef {{ '}' }}) button reference
  • Renderer2.setAttribute() to update ARIA attributes
  • ElementRef.nativeElement.contains(target) to detect clicks outside
  • State isMenuOpen controls visibility

5. Theme Switcher

The theme switch button is in the header (next to the menu). Implements prefers-color-scheme detection and localStorage persistence.

Implemented features:

  • Detect prefers-color-scheme: window.matchMedia('(prefers-color-scheme: dark)')
  • Light/dark toggle: Instant change on click
  • Persistence: localStorage.setItem('theme', 'dark' | 'light')
  • Apply on load: Reads saved preference or detects system
  • Smooth animations: CSS transitions on all components

Priority order:

  1. localStorage - If saved preference exists, use it
  2. prefers-color-scheme - If no preference, detect from system
  3. Default - Dark mode by default

Technical implementation:

  • ngOnInit() initializes theme on load
  • document.documentElement.classList applies global classes
  • :host-context(.dark-mode) in SCSS for conditional styles
  • CSS variables for dynamic colors
