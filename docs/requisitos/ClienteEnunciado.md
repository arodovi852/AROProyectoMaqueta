PROYECTO ANGULAR DWEC: DESARROLLO DE APLICACIÓN WEB INTERACTIVA¶
DESCRIPCIÓN GENERAL¶

Desarrollar una aplicación web completa en Angular que implemente toda la lógica de cliente (interacción con el DOM, eventos, comunicación asíncrona, servicios) de forma coordinada con el diseño visual que estás creando en el módulo DIW.

Ambos proyectos son paralelos y coordinados: mientras en DIW defines la estructura HTML y los estilos CSS, en DWEC implementas la funcionalidad TypeScript. Al final tendrás una única aplicación que combina diseño (DIW) y funcionalidad (DWEC).

Es el mismo proyecto, mismo repositorio, misma URL desplegada. DIW se encarga de la capa visual, DWEC se encarga de la capa funcional.
